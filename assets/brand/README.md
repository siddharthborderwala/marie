# Marie brand

Two colors only:

| Name  | Hex       | Use                      |
|-------|-----------|--------------------------|
| Ink   | `#141413` | near-black (never #000)  |
| Paper | `#F4F3EE` | warm off-white (never #fff) |

**Mark — "Overlap m":** two arches overlapping; the shared region is knocked out.
It reads as an *m*, and as two versions of a file with their difference in the middle.

- `icon.svg` — macOS app icon (ink squircle tile, paper mark, 824px body on a 1024 canvas)
- `mark-paper.svg` / `mark-ink.svg` — the mark alone, for light/dark backgrounds
- `icon-1024.png` — source for `pnpm tauri icon`
